# Semiconductor Internship Hub

Static GitHub Pages website for ECE, VLSI, embedded and semiconductor internship sources.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

No Node.js, database or backend is required.

The page includes search, category filters, mobile responsiveness, a prominent PM Internship Scheme link and external links that open in new tabs.
